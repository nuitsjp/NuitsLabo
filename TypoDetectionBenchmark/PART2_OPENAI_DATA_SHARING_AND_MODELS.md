# 第2部：OpenAI データ共有プログラム（無料枠）の仕様と全モデル単価

OpenAI Developer Platform において提供されている **「Share inputs and outputs with OpenAI（データ共有プログラム）」** に伴う無料トークン枠（Complimentary Tokens）の仕様、および対象 34 モデルの網羅的トークン単価一覧です。

---

## 1. データ共有プログラム（Complimentary Tokens）の仕組み

OpenAI アカウントの Organization 設定にて、API の入出力データをモデル改善・評価用に共有することに同意すると、**毎日リフレッシュされる無料トークン枠** が付与されます。

### ① 利用ティア別の日次無料枠

| ティア (Tier) | 対象モデルグループ 1 (フラグシップ・中位) | 対象モデルグループ 2 (軽量・小型・高速機) |
| :--- | :---: | :---: |
| **Launch / Grow** | **1,000,000 tokens / 日** | **10,000,000 tokens / 日** |
| **Build (ユーザー現在環境)** | **250,000 tokens / 日** | **2,500,000 tokens / 日** |

> **【リフレッシュ周期】**  
> 毎日 UTC 0:00（日本時間 午前 9:00）に全量リセットされ、翌日への繰り越しはありません。

### ② 100〜140文字（誤字補正 Prompt v3: 約380 tokens/回）での日次換算

- **グループ 2 (`gpt-5.6-luna` など)**:
  - 2,500,000 tokens ÷ 380 tokens ＝ **約 6,570 件 / 日 完全無料**
  - 個人開発や社内業務ツールであれば、**事実上コストゼロ（0円）で恒久運用可能**。
- **グループ 1 (`gpt-6-luna` など)**:
  - 250,000 tokens ÷ 399 tokens ＝ **約 626 件 / 日 完全無料**
  - 1日数百件規模の校正であれば、最新鋭 GPT-6 を完全無料で運用可能。

---

## 2. 運用上の重要制約と落とし穴

1. **Tool use (Function calling) は無料枠対象外**:
   - ツール呼び出し（Web検索、関数実行等）を含むリクエストは全トークンが通常課金対象となります。校正タスクは **純粋なテキストプロンプト（Chat Completions API）** で実装する必要があります。
2. **プリペイド残高要件**:
   - 無料枠を利用する場合でも、アカウントのクレジット残高が完全な $0 だと API エラー（429 / Insufficient Quota）になる制限があります。少額（$5程度）のプリペイド残高を維持しておく必要があります。
3. **無料枠超過後の挙動**:
   - 日次枠を使い切ると、即座に通常の従量課金レートに自動移行して継続処理されます。
