# 誤字脱字判定ベンチマーク: OpenAI Decisions API vs TypeSafe AI System One

100〜140文字程度の日本語テキストを対象に、誤字・脱字（タイポ、同音異義語の誤変換、助詞の脱落・重複など）の検出精度、応答速度（レイテンシ）、およびコストを比較検証した結果レポートです。

---

## 1. エグゼクティブサマリー

| 評価軸 | OpenAI Decisions API (`gpt-6-luna`) | TypeSafe AI System One (`jev-latest`) | 優位性・特徴 |
| :--- | :---: | :---: | :--- |
| **平均応答速度** | 425.5 ms | **177.0 ms** | **TypeSafe AI が約 2.4 倍高速**（中央値 162 ms と極めて安定） |
| **P95 応答速度** | 1,289.0 ms | **249.0 ms** | TypeSafe AI は遅延スパイクが極小 |
| **正解率 (Accuracy)** | **90.0%** (27/30) | 80.0% ➡ **86.7%** (閾値0.3時) | 総合正解率は OpenAI が優位 |
| **再現率 (Recall / 検知率)** | 93.3% ➡ **100.0%** (閾値0.4時) | 60.0% ➡ **73.3%** (閾値0.3時) | **OpenAI は誤字脱字の見逃しゼロ達成可能** |
| **適合率 (Precision / 信頼度)**| 87.5% ➡ 83.3% (閾値0.4時) | **100.0%** (過検出ゼロ) | **TypeSafe AI は正常文の誤検知（空振り）が 0 件** |
| **F1 スコア** | **0.903 ➡ 0.909** | 0.750 ➡ **0.846** (閾値0.3時) | 総合判別性能は OpenAI が優位 |
| **1リクエストあたりコスト** | $0.0000206 (約0.0032円) | **$0.0000142 (約0.0022円)** | **TypeSafe AI が約 31% 安価**（100万回でも約2,200円） |

## 2. 検証環境・条件

- **ランタイム**: .NET 10.0.401 (C# コンソールアプリケーション)
- **ソースコード**: [`Program.cs`](./Program.cs)
- **テストデータ**: 全30件（各120〜126文字）
  - 正常文（誤字脱字なし）: 15件（業務連絡、サポート案内、不具合報告、社内通知など）
  - 誤字脱字文: 15件（同音異義語誤変換、助詞抜け、促音抜け、助詞重複、語尾脱落、単語重複など）
- **モデル & エンドポイント**:
  - **OpenAI**: `gpt-6-luna` (`POST https://api.openai.com/v1/decisions`, `predicate` 型クエリ)
  - **TypeSafe AI**: `jev-latest` (`jev-1.13.0`) (`POST https://api.typesafe.ai/v1/systemone`, `noul` 型クエリ)

| :--- | :---: | :---: | :--- |

| **1リクエストあたりコスト** | **$0.0000206** (約 0.0032 円) | **$0.0000142** (約 0.0022 円) | **TypeSafe が約 31% 安価** |
| **10,000 リクエスト時** | **$0.21** (約 32 円) | **$0.14** (約 22 円) | 双方とも数十円レベル |

## 4. エラー傾向・定性分析

### 1. OpenAI Decisions (`gpt-6-luna`)
- **得意な点**:
  - 同音異義語の文脈誤り（「お願い足します」「概算見張り等」「台幅な改善」など）を 0.94〜0.96 の高い確信度で検出。
  - カナの反転（「サトイ」）や促音抜け（「アプリケション」）も 0.83〜0.96 で確実にキャッチ。
  - 閾値 0.4 では「修正バッチ（パッチ）」(0.420) も拾い、**全15件の誤字を 100% 網羅検知**。
- **課題・弱点**:
  - 正常文の過検出が発生（ID:03 認証方式案内: 0.610、ID:07 不具合報告文: 0.520、ID:04 プロジェクト進捗文: 0.410）。専門用語ややや硬い言い回しを誤りと過敏に捉えた傾向あり。

### 2. TypeSafe AI (`jev-latest`)
- **得意な点**:
  - 正常文に対する安定性（偽陽性が 0 件）。正常文15件のスコアはすべて 0.26 以下にとどまり、「正しい文を誤りと指摘しない」信頼性が非常に高い。
  - 文法構造の明確な破綻（助詞重複「がが」、語尾脱落「存じま」、単語重複「経理部前経理部前」、送りがな「ご返信下り」）は 0.67〜0.93 で的確に検知。
  - 閾値 0.3 では「お願い足します」(0.470)、「発生する能性」(0.470) が救済検知。
- **課題・弱点**:
  - **助詞抜け・形態素の微細な文字レベルの抜け**（「ネットワーク機器[の]冗長化」「アプリケ[ー]ション」「とな[っ]ております」）を見逃しやすい（確率 0.10〜0.21）。
  - 公式ドキュメントに「英語が主要であり、CJK（日本語）は同等の精度ではない」とある通り、日本語特有の細かい表記ゆれに対する感度が控えめ。
