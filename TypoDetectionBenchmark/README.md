# 誤字脱字判定ベンチマーク: OpenAI Decisions API vs TypeSafe AI System One

100〜140文字程度の日本語テキストを対象に、誤字・脱字（タイポ、同音異義語の誤変換、助詞の脱落・重複など）の検出精度、応答速度（レイテンシ）、およびコストを比較検証した結果レポートです。

---

## 2. 検証環境・条件

- **ランタイム**: .NET 10.0.401 (C# コンソールアプリケーション)
- **ソースコード**: [`Program.cs`](./Program.cs)
- **テストデータ**: 全30件（各120〜126文字）
  - 正常文（誤字脱字なし）: 15件（業務連絡、サポート案内、不具合報告、社内通知など）
  - 誤字脱字文: 15件（同音異義語誤変換、助詞抜け、促音抜け、助詞重複、語尾脱落、単語重複など）
- **モデル & エンドポイント**:
  - **OpenAI**: `gpt-6-luna` (`POST https://api.openai.com/v1/decisions`, `predicate` 型クエリ)
  - **TypeSafe AI**: `jev-latest` (`jev-1.13.0`) (`POST https://api.typesafe.ai/v1/systemone`, `noul` 型クエリ)

## 4. エラー傾向・定性分析

### 1. OpenAI Decisions (`gpt-6-luna`)
- **得意な点**:
  - 同音異義語の文脈誤り（「お願い足します」「概算見張り等」「台幅な改善」など）を 0.94〜0.96 の高い確信度で検出。
  - カナの反転（「サトイ」）や促音抜け（「アプリケション」）も 0.83〜0.96 で確実にキャッチ。
  - 閾値 0.4 では「修正バッチ（パッチ）」(0.420) も拾い、**全15件の誤字を 100% 網羅検知**。
- **課題・弱点**:
  - 正常文の過検出が発生（ID:03 認証方式案内: 0.610、ID:07 不具合報告文: 0.520、ID:04 プロジェクト進捗文: 0.410）。専門用語ややや硬い言い回しを誤りと過敏に捉えた傾向あり。

### 2. TypeSafe AI (`jev-latest`)
- **得意な点**:
  - 正常文に対する安定性（偽陽性が 0 件）。正常文15件のスコアはすべて 0.26 以下にとどまり、「正しい文を誤りと指摘しない」信頼性が非常に高い。
  - 文法構造の明確な破綻（助詞重複「がが」、語尾脱落「存じま」、単語重複「経理部前経理部前」、送りがな「ご返信下り」）は 0.67〜0.93 で的確に検知。
  - 閾値 0.3 では「お願い足します」(0.470)、「発生する能性」(0.470) が救済検知。
- **課題・弱点**:
  - **助詞抜け・形態素の微細な文字レベルの抜け**（「ネットワーク機器[の]冗長化」「アプリケ[ー]ション」「とな[っ]ております」）を見逃しやすい（確率 0.10〜0.21）。
  - 公式ドキュメントに「英語が主要であり、CJK（日本語）は同等の精度ではない」とある通り、日本語特有の細かい表記ゆれに対する感度が控えめ。

## 7. 誤字補正実測ベンチマーク: `gpt-6-luna` vs `gpt-5.6-luna`

全30件の評価データセット（正常文15件、誤字脱字文15件）に対し、Chat Completions API を用いて実際にテキスト誤字補正を実行した実測結果です。

### ① 実測サマリー比較表

| 評価項目 | `gpt-6-luna` (250K無料枠) | `gpt-5.6-luna` (2.5M無料枠) | 優位性・特徴 |

| **誤字文の修正成功率** | **93.3%** (14/15 件) | **93.3%** (14/15 件) | 同等（同音異義語・助詞抜け・カナ反転等すべて修復） |
| **正常文の維持率 (過剰修正なし)** | **93.3%** (14/15 件) | 73.3% (11/15 件) | **`gpt-6-luna` が圧倒的**（原文を勝手に変えない） |
| **平均応答速度 (Latency)** | 2,403.9 ms | **2,324.5 ms** | ほぼ同等（約 2.3〜2.4 秒） |
| **中央値 (Median)** | **2,063.0 ms** | 2,275.0 ms | 中央値では `gpt-6-luna` が約 200 ms 高速 |
| **平均消費トークン数** | 397.2 tokens | **381.2 tokens** | ほぼ同等（入力約235、出力約150〜160） |

| **1件あたり実コスト (標準単価)** | **$0.000105 (約 0.016 円)** | $0.000223 (約 0.035 円) | **`gpt-6-luna` が約 53% 安価** |
| **1万件あたり標準コスト** | **約 162 円** ($1.05) | 約 345 円 ($2.23) | 双方とも数百円レベル |

### ② 補正挙動と品質の定性評価

1. **誤字脱字文（15件）の修復力**:
   - 両モデルともに、**15件中14件の誤字を完璧に自然な日本語へ修正**しました。
   - 「お願い足します ➡ お願いいたします」「ネットワーク機器冗長化 ➡ ネットワーク機器の冗長化」「アプリケション ➡ アプリケーション」「能性 ➡ 可能性」「特設サトイ ➡ 特設サイト」など、多種多様なエラーを文脈に合わせて正確に復元しました。
   - 唯一両モデルが修正しなかった「修正バッチ（パッチ）」は、IT用語の「バッチ処理」が存在するため、文脈上意図された表現として保持されたものです。

2. **正常文（15件）に対する過剰修正（余計な改変）の差**:
   - **`gpt-6-luna` (維持率 93.3%)**: 「誤字がなければそのまま出力せよ」というプロンプト指示を極めて厳密に守り、15件中14件を一文字の狂いもなく完全一致で出力しました。
   - **`gpt-5.6-luna` (維持率 73.3%)**: 4件で過剰修正（「予定通り ➡ 予定どおり」「OAuth2.0 ➡ OAuth 2.0」「80点以上の獲得 ➡ 取得」など）が発生し、誤字ではない部分を勝手に言い換える傾向が見られました。

### ③ 結論と運用推奨

- **品質・指示遵守を最優先する場合**: **`gpt-6-luna`** を強く推奨します。
  - 原文のニュアンスを壊さずピンポイントで誤字のみを修正する能力が優れており、1日あたり約 629 件まで完全無料で、超過後も 1 万件あたり約 162 円と破格です。
- **1日数千件規模を完全無償で回したい場合**: **`gpt-5.6-luna`**（または `gpt-4o-mini`）が適しています。
  - 1日約 6,500 件まで無料枠内で運用可能です。ただし、微細な表現の言い換えが発生する可能性がある点に留意が必要です。

## 8. プロンプト最適化による `gpt-5.6-luna` の過剰修正改善（Prompt v2）

`gpt-5.6-luna` における正常文の過剰修正（73.3%）を改善するため、「推敲・意訳の明示的禁止」「表記ゆれ・読点追加の禁止」を明記した厳格プロンプト（Prompt v2）を適用した検証結果です。

### ① プロンプト改善ルール (Prompt v2)
1. **推敲・リライトの禁止**: より自然な表現への言い換え、語彙の変更（例:「獲得」➡「取得」）を厳禁。
2. **表記ゆれ・句読点変更の禁止**: ひらがな化（例:「予定通り」➡「予定どおり」）、スペース挿入（例:「OAuth2.0」➡「OAuth 2.0」）、読点追加を禁止。
3. **原則完全維持**: 明確な誤字脱字・文法崩壊がない限り、一文字も変えず完全一致で出力。

### ② 改善前後の指標比較 (Before / After)

| 指標 | 初期プロンプト (v1) | 最適化プロンプト (v2) | 改善効果 |
| :--- | :---: | :---: | :--- |
| **正常文の維持率 (過剰修正なし)** | 73.3% (11/15) | **93.3% (14/15)** | **+20.0 pt 改善！(`gpt-6-luna` と同等)** |
| **誤字文の修正着手率** | 93.3% (14/15) | **86.7% (13/15)** | -6.6 pt（助詞抜け1件が原文維持判定に） |
| **平均レスポンスタイム** | 2,324.5 ms | **1,873.4 ms** | **約 450 ms 高速化**（不要な推論が抑制） |

### ③ 分析と成果
- 正常文で発生していた「OAuth2.0」「予定通り」「獲得」の勝手な言い換えが **すべて解消され、完全一致で維持** されるようになりました。
- 不要な推論（Reasoning tokens）の発生が抑制されたことで、**平均応答速度も 1.8 秒台まで向上** しました。
- 結論として、**プロンプトの工夫によって `gpt-5.6-luna` でも `gpt-6-luna` 同等の 93.3% の正常文維持率を達成可能** であることが実証されました。
