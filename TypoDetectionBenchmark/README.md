## 1. エグゼクティブサマリー

```
【入力: 100〜140文字の日本語テキスト】
         │
         ▼
【Step 1: 高速・低コスト判定】
  ・TypeSafe AI (最適化Criteria / 閾値 0.2〜0.3): 正解率 93.3% / 288 ms / 見逃し1件のみ
  ・OpenAI Decisions (シンプル指示 / 閾値 0.4): 再現率 100%（見逃しゼロ） / 正解率 90.0% / 280 ms
         │
    誤字脱字あり？
   ├── No  ─▶ そのまま通過・確定（追加コスト 0 円 / 即時完了）
   └── Yes ─▶ 【Step 2: 自動補正（Prompt v3）】
                ・gpt-5.6-luna (250万tok/日 無料枠): 1.58 秒 / 正常文100%維持 & 誤字100%修復
                ・gpt-6-luna   (25万tok/日 無料枠):  2.05 秒 / 正常文100%維持 & 誤字100%修復
```

1. **高速判定（Step 1）における適正プロンプトの発見**:
   - **TypeSafe AI (`jev-latest`)** は、誤字・表記ゆれの境界を明示した最適化Criteriaを与えることで、正解率 86.7% ➡ **93.3%（F1: 0.933）** へ大幅向上。
   - **OpenAI Decisions (`gpt-6-luna`)** は、長文ルールを投入すると疑心暗鬼になり過検知が増加するため、**シンプルな指示（標準プロンプト）** の方が **正解率 90.0%（再現率 100.0%・見逃しゼロ）** の最高性能を発揮。
2. **完全無料枠（Data Sharing Program）の活用**:
   - ユーザーアカウント（**Build ティア**）において、入出力データ共有を有効化することで、**`gpt-5.6-luna` は毎日 250 万トークン（約 6,500 件/日）**、**`gpt-6-luna` は毎日 25 万トークン（約 630 件/日）** が完全無料で利用可能。
3. **補正（Step 2）におけるプロンプト精緻化のブレークスルー**:
   - 具体例付きで境界を定義した **Prompt v3** により、**`gpt-6-luna` および `gpt-5.6-luna` の両モデルで「正常文維持率 100.0%」かつ「誤字修正率 100.0%」（全30件パーフェクト）を達成**。特に `gpt-5.6-luna` は平均 **1.58 秒** と最速。

## 3. 推奨アーキテクチャとモデル選定の結論

### 2段階パイプライン構成
1. **リアルタイム性・誤報防止重視（UI入力フォーム等）**:
   - **Step 1**: **TypeSafe AI System One (`jev-latest`) ＋ 最適化Criteria**（応答 280ms / 正解率 93.3%）
   - **Step 2**: 警告検知時のみ **`gpt-5.6-luna` ＋ Prompt v3** で自動補正（応答 1.58秒 / 無料枠で毎日6,500件まで無料）。
2. **見逃しゼロ重視（バッチ処理・重要文書検査等）**:
   - **Step 1**: **OpenAI Decisions API (`gpt-6-luna`) ＋ シンプル指示**（再現率 100.0% / 見逃し 0 件）
   - **Step 2**: 誤字判定テキストを **`gpt-5.6-luna`（無料枠内）** または **`gpt-6-luna`（大規模有料時）** で補正。
